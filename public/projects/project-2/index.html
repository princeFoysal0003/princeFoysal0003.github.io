IoT-Based Real-Time Air Quality and Hazard Detection System using Arduiono Uno and ESP8266

Authors: Prince Foysal (EEE, RUET), Amit Hasan (EEE, RUET), Naim Sikder (EEE, RUET)

Date: 2025-04-13 00:00:00 +0000 UTC


Abstract

The IOT-based Air Quality Monitoring System is an Arduino based project designed to measure and display real-time air quality,air humidity and temperature,the quantity of air pollutant such as Carbon Monoxide(CO) in the air.This system is also capable of detecting LPG gas in case of gas leakage in house. Poor indoor air quality and potential gas leaks can lead to significant health and safety concerns in modern households. Traditional methods of monitoring environmental factors such as temperature, humidity, and gas levels are often inadequate and inconsistent. This system provides real-time data and instant alerts to a mobile app named IOT Cloud, ensuring users are always updated, regardless of location. By leveraging low-cost sensors and smart technology, the project improves household safety and promotes environmental consciousness in addition with smart home automation. This project employs an Arduino Uno microcontroller interfaced with an MQ135 gas sensor to detect various air pollutants, a DHT11 sensor to measure temperature and humidity,an MQ-06 LPG gas sensor to detect LPG gas leakage,an MQ-07 carbon monoxide sensor to measure the concentration of carbon monoxide in air and an ESP8266 wi-fi module to transmit the data through wi-fi and the data will be displayed on IOT CLOUD app. The MQ135 sensor provides analog readings corresponding to the concentration of gases like ammonia, benzene, and carbon dioxide. These readings are transformed into percentage which indicates the percentage of good air.The temperature and humidity data is in degree and percentage respectively.The MQ-06 and MQ-07 sensors data are transformed in Parts Per Million(PPM) [1].

Required Components

  1. Arduino Uno
  2. ESP8266 Wi-Fi module
  3. MQ-07 Carbon Monoxide (CO) Gas Sensor
  4. MQ-135 Air Quality ($CO_2, NH_3$, Benzene, and Smoke) Gas Sensor
  5. MQ-06 LPG Gas Sensor
  6. DHT11 Temperature and Humidity Sensor

	void loop() {
		ArduinoCloud.update();
		float hm = dht.readHumidity();
		float temp = dht.readTemperature();
		int airQualityValue = analogRead(sensor);airQualityValue = constrain(airQualityValue, 100, 900);
		int airQualityPercent = map(airQualityValue, 900, 100, 0, 100);
		if (arduinoSerial.available()) {
		String data = arduinoSerial.readStringUntil('\n');
		int commaIndex = data.indexOf(',');
		if (commaIndex > 0) {
		valA0 = data.substring(0, commaIndex).toInt();
		valA1 = data.substring(commaIndex + 1).toInt();
		}
		}
		temperature = temp;
		humidity = hm;
		airQuality = airQualityPercent;
		lpg = valA0;
		carbonMonox = valA1;
	}
